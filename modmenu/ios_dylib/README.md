# iOS dylib — قالب عميل المود مينو

قالب Objective-C يقرأ إعدادات لوحة التحكم من
`GET /api/modmenu/config` ويطبّقها محلياً داخل اللعبة المعدّلة.

## خطوات الاستخدام

1. عدّل `kConfigURL` إلى رابط لوحة التحكم لديك (عنوان البروكسي والمنفذ).
2. فكّ IPA اللعبة واعثر على الدوال الحقيقية (المباراة/النتيجة/ذكاء الخصم).
3. اربطها مكان أسطر `TODO` في `ModMenu.m`.
4. ابنِ الـdylib:

```bash
export THEOS=~/theos
make package
```

5. احقن الـdylib في الـIPA (مثلاً بـ `optool` أو `insert_dylib`)،
   وأضف `LC_LOAD_DYLIB`.
6. وقّع وثبّت عبر ESign/Feather على iPhone 13 (راجع
   `docs/KNOWLEDGE_BASE_V2_mod_menu_proxy.md` للشهادات وTrust).
7. اضبط البروكسي على الواي فاي → التطبيق المعدّل يقرأ الإعدادات تلقائياً.

> **تحذير:** الميزات تُطبّق فقط في **المباريات الآفلانية** — أي تفعيل
> أثناء لعب أونلاين قد يؤدي لحظر دائم (راجع `docs/OFFLINE_MOD_MENU.md`).
