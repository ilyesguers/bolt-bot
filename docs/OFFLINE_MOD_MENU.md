# 🛠️ مود مينو — مباريات الآفلان ضد AI (Client-Side)

> وثيقة فنية توضح لماذا تعمل هذه الميزات في المباريات الآفلانية فقط، وكيف
> يقرأها التطبيق المعدّل من لوحة التحكم. **التعديل على اللعبة يخالف شروط
> الخدمة وقد يؤدي لحظر الحساب** — خاصة في الأحداث المرتبطة بالسيرفر.

---

## 1) لماذا "الآفلان" مختلف؟

| الوضع | أين تُلعب المباراة؟ | هل يراها البروكسي؟ | هل التعديل ممكن؟ |
|-------|--------------------|--------------------|------------------|
| **أونلاين (PVP)** | على السيرفر + التحقق منه | نفق TLS فقط (حجم/توقيت) | ❌ مستحيل عبر أي وسيلة خارج الجهاز |
| **آفلان ضد AI** | **على جهازك بالكامل** | لا (شبكة = مزامنة فقط) | ✅ داخل التطبيق المعدّل (Client-Side) |

في المباراة ضد الكمبيوتر، ذكاء الخصم والنتيجة تُحسب محلياً. السيرفر لا
يتحقق من كل لحظة — فقط يستلم المزامنة، وقد يتحقق من النتيجة عند رفعها
(خاصة في الأحداث). لهذا:

- التعديلات "الأسطورية" (إنهاء فوراً، فوز تلقائي، AI بطيء...) تنفع فيها،
  لأنها تعديل لعمليات على **جهازك**.
- لكن التطبيق يتم **داخل اللعبة المعدّلة نفسها** — البروكسي مجرد قناة
  تحكم لا يلمس بيانات المباراة.

---

## 2) المعمارية

```
لوحة التحكم (هذا المشروع)
        │  POST/GET /api/modmenu  (أنت، من المتصفح)
        ▼
data/modmenu.json  ──►  GET /api/modmenu/config
                                │
                التطبيق المعدّل (IPA + dylib) يقرأها كل N ثانية
                                ▼
        يطبّق الميزة محلياً داخل اللعبة (إنهاء/إبطاء/...)
```

**التطبيق المعدّل يصل للوحة التحكم عبر نفس اتصال البروكسي:**
`http://<PROXY_IP>:<PORT>/api/modmenu/config` — البروكسي يمرر طلبات HTTP
العادية إلى اللوحة مباشرة.

---

## 3) صيغة الإعداد (JSON)

`GET /api/modmenu/config` يرجع:

```json
{
  "protocol": 1,
  "features": {
    "instant_finish": true,
    "auto_win": false,
    "slow_ai_client": true,
    "ai_miss_client": false,
    "stamina_client": false,
    "stats_max_client": false
  },
  "updated_at": 1754668800.0,
  "note": "يقرأها التطبيق المعدل؛ التعديل Client-Side على جهازك فقط."
}
```

### المفاتيح

| المفتاح | المعنى |
|---------|--------|
| `instant_finish` | إنهاء المباراة فوراً وتسجيل النتيجة لصالحك |
| `auto_win` | تثبيت النتيجة محلياً (مثل 3-0) |
| `slow_ai_client` | إبطاء حركة خصم الكمبيوتر |
| `ai_miss_client` | تسديدات الخصم خارج المرمى |
| `stamina_client` | ستامينا لا تنقص |
| `stats_max_client` | قيم اللاعبين 99 داخل المباراة |

إذا فعّلت `DASHBOARD_TOKEN` أضف `?token=...` إلى الرابط.

## 4) جانب الجهاز: حقنة dylib

القالب الجاهز في `modmenu/ios_dylib/ModMenu.m`. الفكرة:

1. عند تحميل اللعبة المعدّلة، اقرأ الإعدادات من اللوحة كل 3-5 ثوانٍ
   (خيط خلفي).
2. اربط (Hook) الدوال المسؤولة عن: حالة المباراة، النتيجة، ذكاء الخصم.
   **أسماء الدوال الحقيقية تُكتشف بفك الـ IPA** — القالب يترك مكانها
   `// TODO: اربط دالة اللعبة هنا`.
3. عند تفعيل `instant_finish` مثلاً: استدعِ دالة إنهاء المباراة في اللعبة
   (أو اعدّل متغير النتيجة في الذاكرة) مباشرة.

### البناء

```bash
# يتطلب theos على جهاز ماك + iPhone مخترق أو IPA معدل للتوقيع
export THEOS=~/theos
make package
# ثم ESign / Feather مع الشهادة (انظر docs/KNOWLEDGE_BASE_V2)
```

### التثبيت والتشغيل

1. سخّب اللعبة الأصلية من متجر App Store.
2. اعكس الـIPA وفكّ التشفير (جهاز مخترق أو نسخة مسربة).
3. ادمج الـdylib في التطبيق وفعّل `-eFootballMod` في `LC_LOAD_DYLIB`.
4. وقّع بتوقيع مطوّر (ESign/Feather) وثبّته — ثم **Trust** للملف التعريفي.
5. اضبط البروكسي على شبكة الواي فاي ليصل التطبيق للوحة التحكم.

---

## 5) المخاطر — اقرأها قبل التنفيذ

| السيناريو | الخطر |
|-----------|-------|
| مباراة آفلان نقية (تدريب/جولة) | منخفض — لا رفع نتيجة للسيرفر |
| حدث مرتبط بالسيرفر (AI Challenge) | متوسط — النتيجة تُتحقق عند الرفع |
| أي نشاط أونلاين مع تعديل محلي | **عالي — حظر دائم** |

اللعبة تقارن بيانات جهازك مع السيرفر (Desync Detection). إذا كانت
النتيجة المرسلة تتعارض مع إشاراتها، يرفضها أو يحظر. التعديلات
**المرئية/المحلية فقط** هي الأقل خطورة، وكل ما يؤثر على نتيجة
مُرفَعة للسيرفر يزيد الخطر.

---

## 6) ما الجاهز في هذا المشروع

- ✅ `GET/POST /api/modmenu` — لوحة تحكم كاملة (الواجهة + الحفظ الذرّي)
- ✅ `GET /api/modmenu/config` — صيغة خفيفة للتطبيق المعدّل
- ✅ كشف تقديري لنمط المباراة (`آفلان ضد AI` / `أونلاين`) في اللوحة
- ✅ إشعارات عند كل حفظ وتغيير
- ⏳ الجانب المتبقي (خارج هذا المستودع): هندسة الـIPA، اكتشاف الدوال،
  التوقيع — يحتاج جهاز ماك + أدوات iOS.
