# قاعدة المعلومات التقنية الشاملة — مشروع أداة تخصيص eFootball (PES Mobile) عبر بروكسي
> تاريخ الإعداد: 2026-08-07 — بيئة العمل: Railway + GitHub + iPhone 13 — التكلفة المستهدفة: $0
> **تنبيه مهم:** هذه الوثيقة تعليمية وتحليلية فقط. أي تعديل لبيانات اللعبة المتبادلة مع خوادم KONAMI يخالف شروط الخدمة وقد يؤدي لحظر دائم للحساب.

## 1) الفكرة المقترحة وتحليل الجدوى

### الفكرة كما طرحتها
اعتراض البيانات بين تطبيق eFootball على iPhone وخادم KONAMI عبر بروكسي، ثم تعديلها (مثلاً: طاقات لاعبين، عملات، فتح بكجات).

### لماذا هذه الفكرة عالية الخطورة تقنياً وقانونياً؟
1.  **لعبة Online-Competitive:** كل القيم الحاسمة (رصيد GP/Coin، طاقات اللاعبين، نتائج المباريات) محسوبة ومُتحقق منها **Server-Side**. أي تعديل محلي يُكتشف فوراً عند المزامنة ويُرفض.
2.  **مخالفة ToS:** بنود KONAMI تمنع Reverse Engineering و Man-in-the-Middle والتعديل. العقوبة: حظر الجهاز/الحساب وفقدان المشتريات.
3.  **iOS مغلق:** آبل تمنع تثبيت شهادات جذر أو تعديل حركة تطبيقات أخرى بدون Jailbreak أو شهادة مطور مدفوعة/MDM — وهذا يتعارض مع شرطك "دون شهادات خارجية".

**الخلاصة:** المسار "تعديل بيانات الخادم لربح داخل اللعبة" غير واقعي بدون اختراق الخادم نفسه، وهذا غير قانوني ومستحيل ضمن ميزانية $0.

### بدائل مشروعة مقترحة ضمن نفس المهارات (تحقق نفس الهدف "تخصيص" بدون غش)
- **أداة تحليل تكتيكي محلية:** بروكسي **قارئ فقط (Read-Only)** يعرض إحصائيات الشبكة (Ping, Packet loss, استهلاك البيانات) + مساعد بناء تشكيلة Offline.
- **Companion App:** موقع/بوت يحلل لقطات الشاشة (OCR) لاقتراح تطوير اللاعبين — بدون لمس حركة الشبكة.
- **مختبر تعليمي:** بروكسي تدريبي على تطبيق تجريبي تملكه أنت (وليس eFootball) لتعلم مبادئ الشبكات.

> إذا أصررت على مسار الاعتراض والتعديل، سأشرح لك في القسم 3 لماذا سيفشل على iPhone 13 غير المكسور، حتى لا تضيع وقتك ومالك.

## 2) بيئة العمل المحددة

### 2.1 Railway — منصة النشر ($0)
- **الخطة المجانية الحالية:** رصيد تجريبي ~$5 شهرياً، الخدمة تنام بعد الخمول، لا يوجد IP ثابت مجاني.
- **القيود:** لا يمكنك فتح منافذ عشوائية، فقط `PORT` الذي تعطيه المنصة (عادة 8080). البروكسي التقليدي يحتاج منفذ 8080/3128 ثابت + عنوان IP عام — Railway يعطيك Domain فقط (`xxx.up.railway.app`) مع Reverse Proxy.
- **البديل المجاني:** Fly.io / Render / Replit لكن كلها نفس القيد: بروكسي HTTP يعمل عبر WebSocket أو CONNECT غير مدعوم جيداً مجاناً.
- **التكلفة الخفية:** استهلاك الباندويث للبروكسي عالي جداً (كل بايت من اللعبة يمر عبر Railway) — سينفد الرصيد المجاني خلال ساعات.

### 2.2 GitHub — إدارة الإصدارات
- مجاني بالكامل للمستودعات العامة/الخاصة.
- ستحتاج `.gitignore` يمنع رفع الشهادات/المفاتيح، و `GitHub Actions` للنشر التلقائي على Railway.

### 2.3 iPhone 13 — الجهاز المستهدف
- **iOS 16-18:** يدعم إعداد بروكسي يدوي **لكل شبكة Wi-Fi فقط** (الإعدادات > Wi-Fi > ⓘ > تكوين البروكسي > يدوي). لا يوجد بروكسي عام على بيانات الجوال بدون ملف تكوين VPN/Profile.
- **بدون Jailbreak:** لا يمكنك تثبيت شهادة CA كـ Trusted للـ System Store بسهولة، وتطبيقات مثل eFootball ترفضها حتى لو ثبتها (انظر قسم 3).
- **Jailbreak:** غير متاح بشكل مستقر لـ iPhone 13 على iOS الحديث، ويُفقد الضمان ويُكتشف من اللعبة.

## 3) لماذا "بدون شهادات خارجية" = مستحيل لاعتراض HTTPS؟

هذه أهم نقطة تقنية في المشروع كله:

### 3.1 كيف تعمل اللعبة
1.  التطبيق يفتح اتصال **TLS 1.2/1.3** مباشر مع `*.konami.net`
2.  يتحقق من شهادة الخادم عبر **Certificate Pinning** — الشهادة/المفتاح العام مضمن داخل كود التطبيق نفسه، وليس فقط في متجر iOS.
3.  البيانات مشفرة + موقعة (غالباً `protobuf` أو `json` + HMAC). حتى لو فككت التشفير، الخادم سيتحقق من التوقيع.

### 3.2 ماذا يفعل البروكسي التقليدي (مثل Charles / mitmproxy)
- ينشئ شهادة مزورة لكل موقع ويطلب من الهاتف الوثوق بها عبر تثبيت ملف `CA.crt`.
- **على iPhone بدون شهادة:** الاتصال سيفشل برسالة `SSL Handshake Failed` ولن تفتح اللعبة أصلاً.
- **حتى مع تثبيت الشهادة يدوياً:** تطبيقات كبرى مثل eFootball و Free Fire و PUBG تطبق Pinning → تكتشف الشهادة المزورة وترفض الاتصال أو تُغلق التطبيق.

### 3.3 طرق تجاوز Pinning (ولماذا لا تنطبق على شروطك)
- **Jailbreak + SSL Kill Switch 2:** يتطلب كسر حماية.
- **Frida / Objection + إعادة توقيع IPA:** يتطلب شهادة مطور مدفوعة ($99/سنة) أو Sideload كل 7 أيام + كمبيوتر.
- **تعديل Binary:** يبطل توقيع آبل → لا يثبت بدون شهادة خارجية.

> **النتيجة:** شرط "بدون أي شهادات خارجية + iPhone غير مكسور" يلغي إمكانية اعتراض وتعديل حركة eFootball من الأساس. أي فيديو يوتيوب يدعي عكس ذلك إما مفبرك أو يستخدم حساب Offline قديم.

## 4) إذا أردنا بناء بروكسي تعليمي (قارئ فقط) — ماذا نحتاج؟

هذا هو الحد الأقصى الممكن ضمن قيودك وبدون مخالفة:

### المعمارية المقترحة
```
[iPhone 13 - WiFi Proxy Manual] --> [Railway App: Node.js/Python Proxy] --> [Internet]
                                      |
                                      +--> لوحة تحكم Web لعرض الإحصائيات فقط
```

### المكدس التقني المقترح ($0)
- **اللغة:** Python (mitmproxy) أو Node.js (http-proxy-middleware) — كلاهما يعمل على Railway.
- **البروتوكول:** HTTP Proxy عادي (ليس Transparent). يدعم فقط تطبيقات تحترم إعدادات النظام — eFootball قد يتجاهلها.
- **الواجهة:** صفحة Web بسيطة تعرض: حجم البيانات، زمن الاستجابة، الأخطاء — بدون فك تشفير HTTPS.
- **التخزين:** لا حاجة لقاعدة بيانات، فقط Logs مؤقتة (Railway يحذفها بعد إعادة التشغيل).

### ما لن نستطيعه
- فك تشفير حركة eFootball
- تعديل أي قيمة وإرسالها للخادم
- العمل على بيانات الجوال بدون VPN Profile

## 5) العوائق المتوقعة وحلولها (Matrix)

| العائق | السبب | الحل الواقعي | هل يتعارض مع $0 / بدون شهادة؟ |
|---|---|---|---|
| اللعبة لا تتصل عند تفعيل البروكسي | Pinning + TLS | لا حل بدون كسر Pinning | نعم، يتعارض |
| Railway يوقف الخدمة بعد 5 دقائق خمول | Free tier | إبقاء Ping كل دقيقة (يستهلك الرصيد) | يزيد التكلفة |
| iPhone لا يطبق البروكسي على اللعبة | اللعبة تستخدم QUIC/UDP | لا يمكن فرضه بدون VPN | نعم |
| حظر الحساب بعد محاولة تعديل | كشف Server-Side | التوقف فوراً، عدم الإرسال للخادم | - |
| الحاجة لـ IP ثابت | Railway يعطي Domain متغير | استخدام Cloudflare Tunnel (مجاني لكن معقد) | ممكن لكن غير مستقر |

## 6) الجانب القانوني والأخلاقي
- **KONAMI ToS §5:** يحظر أي أداة تغير تجربة اللعب العادلة.
- **قانون الألفية للملكية الرقمية (DMCA):** تجاوز الحماية التقنية قد يكون مخالفة قانونية في بعض الدول.
- **آبل:** تطبيقات البروكسي التي تدعي تعديل ألعاب أخرى تُرفض من App Store.
- **التوصية:** ابقِ المشروع في إطار **تحليل أداء الشبكة + أدوات مساعدة Offline** — هذا آمن 100% وقابل للنشر والربح (إعلانات، اشتراك).

## 9) الخلاصة التنفيذية

> **بشروطك الحالية (iPhone 13 بدون Jailbreak + بدون شهادات + تكلفة صفر + Railway): لا يمكن بناء أداة تعديل حقيقية لـ eFootball تعمل Online.** أي محاولة ستفشل عند أول اتصال TLS بسبب Pinning، وإن نجحت ستؤدي لحظر فوري.

**المسار الواقعي الوحيد:** بناء أداة مساعدة **Offline** (بناء تشكيلة، حساب تطوير اللاعبين، تحليل Ping) + بروكسي **تعليمي للمراقبة فقط** — هذا يحقق فكرة "التخصيص" بدون غش، قابل للنشر على Railway مجاناً، ولا يحتاج شهادات.
